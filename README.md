# Notes

A modern note-taking app with a rich text editor, built with Next.js and TipTap.

## Features

- Rich text editing with TipTap
- User authentication
- Organized notes with folders
- Dark/light theme support
- Auto-save

## Tech Stack

- **Framework:** Next.js 16, React 19
- **Editor:** TipTap
- **Database:** Neon (PostgreSQL) + Drizzle ORM
- **Auth:** better-auth
- **Styling:** Tailwind CSS, SASS
